# Support

This document outlines the various ways you can get support for CSV Toolset.

## Getting Help

### 📚 Documentation
- Check our [documentation](docs/) first
- Review the [getting started guide](docs/tutorials/getting_started.md)
- Look through tool-specific guides in [docs/tools/](docs/tools/)

### 🐛 Bug Reports
1. Search [existing issues](../../issues) first
2. If your issue isn't listed, create a new one using our [bug report template](../../issues/new?template=bug_report.md)
3. Include all requested information in the template
4. Add CSV file details when relevant (size, format, encoding)

### 💡 Feature Requests
1. Review [existing feature requests](../../issues?q=is%3Aissue+is%3Aopen+label%3Aenhancement)
2. Submit new requests using our [feature request template](../../issues/new?template=feature_request.md)
3. Include clear use cases and performance requirements

### 🤝 Community Support
- Use [GitHub Discussions](../../discussions) for:
  - Q&A
  - Best practices
  - Tool usage tips
  - Integration examples
  - Performance optimization

### 🔒 Security Issues
- **DO NOT** report security vulnerabilities through public GitHub issues
- Follow our [security policy](SECURITY.md) for responsible disclosure
- Report security issues via email to [INSERT_SECURITY_EMAIL]

## Best Practices

### Before Seeking Help
1. Update to the latest version
2. Check the changelog for recent changes
3. Review relevant documentation
4. Search existing issues and discussions

### When Reporting Issues
1. Use clear, descriptive titles
2. Provide complete reproduction steps
3. Include environment details
4. Attach minimal example files
5. Describe expected vs actual behavior

### Response Times
- Bug reports: 2-3 business days
- Feature requests: 5-7 business days
- Security issues: 48 hours
- General questions: 3-5 business days
