# Security Policy

## Reporting a Vulnerability

We take the security of CSV Toolset seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to [INSERT_SECURITY_EMAIL]. You should receive a response within 48 hours.

Please include the following information:
* Type of issue
* Full paths of source file(s) related to the issue
* Location of the affected source code
* Any special configuration required to reproduce the issue
* Step-by-step instructions to reproduce the issue
* Proof-of-concept or exploit code (if possible)
* Impact of the issue, including how an attacker might exploit it

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |

## Security Best Practices

When using CSV Toolset:
1. Always validate input files before processing
2. Use appropriate file permissions
3. Keep the software updated to the latest version
4. Review output files for sensitive data before sharing
5. Follow the principle of least privilege when setting up automation

## Updates and Patches

Security updates will be released as needed. Users will be notified through:
* GitHub Security Advisories
* Release notes
* The project's changelog
